Privacy Policy

This policy explains how TR Domain Scout handles information when used by its operator and how this public information website works.

1. Scope

TR Domain Scout is a private, locally operated research utility. It is not a public account-based service. This website provides information about the application and does not run the research tool.

2. Information processed by the application

The local application may process the following information supplied by its operator:

  • keywords, brand names, search-volume ranges, and selected domain extensions;
  • API configuration identifiers and credentials required to contact authorized services;
  • keyword metrics, public-source results, and RDAP domain-status responses.

3. Google Ads API data

Google Ads API access is performed using a dedicated service account that has been granted access by the operator. The application requests keyword-planning information for research purposes. It does not create or modify campaigns, advertisements, budgets, users, billing profiles, or payment methods.

4. Storage and retention

The application runs on the operator's computer. Credentials are read from local configuration and are not intentionally transmitted to this public website. Active research jobs are held in the local process memory. Exported CSV files are saved only when the operator requests a download and remain under the operator's control.

5. Third-party services

Depending on the selected workflow, the application may communicate with:

  • Google Ads API for keyword-planning metrics;
  • Yandex Search API / Wordstat for search-query metrics;
  • IANA-listed RDAP services for domain-registration status;
  • public web sources explicitly selected by the operator.

Each provider processes requests under its own terms and privacy policy.

6. This public website

This is a static informational website. It does not use account registration, advertising pixels, or analytics scripts, and it does not intentionally set cookies. The hosting provider may process basic request logs for security and reliable delivery under its own policies.

7. Sharing and sale

TR Domain Scout does not sell personal information. Information is sent only to the services required to perform an operator-requested research action or when disclosure is required by law.

8. Security

Access credentials should remain on the operator's device and must not be placed in public repositories. The operator is responsible for limiting account permissions, rotating credentials, and securing local exports.

9. Changes

This policy may be updated as the application changes. The effective date at the top of this page will be revised when material changes are published.

10. Contact

Questions about this policy may be sent to dimcomercial@gmail.com.
