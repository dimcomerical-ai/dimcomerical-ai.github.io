Privacy Policy

This policy explains what information TR Domain Scout accesses, why it is used, where it is stored, when it is shared, how long it is retained, and how it can be deleted. It also explains how this public informational website operates.

1. Application identity and scope

TR Domain Scout is a private, locally operated keyword-planning and domain-research application. It is operated by an independent developer and used by a single authorized operator. It is not a public account-based or multi-user service. This website provides public information about the application and does not run the research tool. No login is required to view this website.

2. Information processed by the application

The local application may process the following categories of information:

  • research inputs supplied by the operator, including keywords, brand names, language, location, search-volume ranges, and selected domain extensions;
  • technical configuration, including Google Ads customer identifiers, developer-token configuration, and credentials required to contact authorized services;
  • Google Ads API keyword ideas, aggregated historical search metrics, competition indicators, and related planning results;
  • public-source research results and RDAP domain-registration status responses;
  • local job status and error messages required to operate and troubleshoot the application.

The application does not request access to Google profile information, Gmail, Contacts, Calendar, Drive, Photos, precise location, health information, or other personal Google-account content.

3. Google Ads API access and purpose

Google Ads API access is performed using a dedicated service account that has been granted access by the operator to the operator-controlled Google Ads account. The application uses this access only to request aggregated keyword ideas and keyword-planning metrics for Türkiye. These results help the operator compare potential search topics before making independent business decisions.

TR Domain Scout does not create or modify campaigns, advertisements, audiences, conversion actions, budgets, users, billing profiles, or payment methods. It does not sell Google API data, use it for personalized advertising, or use it to build profiles about other people.

4. How information is used

Information is used only to perform an operator-requested research workflow:

  • submit selected keywords and targeting parameters to authorized keyword-planning services;
  • display and sort returned metrics for manual review;
  • check selected domain extensions through public RDAP services;
  • create a local CSV export when the operator explicitly requests one;
  • diagnose technical errors and enforce API limits.

5. Storage, retention, and deletion

The application runs on the operator's computer. Credentials are read from local configuration and are not transmitted to this public website. Active research inputs and results are held in local process memory for the duration of the research session and are discarded when the application process stops, except for information the operator intentionally exports.

Exported CSV files remain on the operator's device until the operator deletes them. Local credentials and configuration remain until the operator removes or rotates them. The application does not maintain a developer-controlled cloud database of research results or Google API data. Deletion is performed by deleting local exports and configuration files and, where applicable, revoking the service account's access in Google Ads.

6. Sharing, disclosure, and sale

TR Domain Scout does not sell personal information or Google API data. It does not share information with data brokers, advertising networks, or unrelated third parties. Information is transmitted only to the service selected by the operator to complete a research request, or when disclosure is required by law. No human reviews research results unless the operator chooses to share a local export.

7. Third-party services

Depending on the selected workflow, the application may communicate with:

  • Google Ads API for keyword-planning metrics;
  • Yandex Search API / Wordstat for search-query metrics;
  • IANA-listed RDAP services for domain-registration status;
  • public web sources explicitly selected by the operator.

Each provider processes requests under its own terms and privacy policy. TR Domain Scout's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

8. This public website

This is a static informational website. It does not use account registration, advertising pixels, or analytics scripts, and it does not intentionally set cookies. The hosting provider may process basic request logs for security and reliable delivery under its own policies.

9. Security safeguards

Credentials are stored only in local configuration, are excluded from the public website and public source repository, and should be protected by operating-system access controls. The operator is responsible for using least-privilege account permissions, rotating credentials, securing local exports, and revoking access that is no longer required. Network requests use HTTPS where supported by the service provider.

10. Operator choices and data controls

The operator controls which keywords are submitted, which services are contacted, whether a CSV file is exported, and when local files are deleted. Google Ads access can be withdrawn by removing the service account from the relevant Google Ads account. Privacy questions or deletion requests concerning any information under the developer's control may be sent to the contact address below.

11. Children's privacy

TR Domain Scout is a private business-research tool and is not directed to children. The application does not knowingly collect personal information from children.

12. Prohibited content and AI-generated imagery

The application does not generate, upload, distribute, or facilitate AI-generated non-consensual intimate imagery, intimate imagery of any kind, or other prohibited content. Its functionality is limited to text-based keyword metrics and domain-status research.

13. Changes

This policy may be updated as the application changes. The effective date at the top of this page will be revised when material changes are published.

14. Contact

The privacy contact and developer contact for TR Domain Scout is dimcomercial@gmail.com. Questions about this policy, access, correction, or deletion may be sent to this address.
