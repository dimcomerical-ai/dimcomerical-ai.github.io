Private research utility

Turkish keyword and domain research, in one local workflow.

TR Domain Scout is a single-operator tool under development. It helps its operator review Turkish-language keyword demand, check selected domain extensions, and export research results.

How it works Read the privacy policy →

Local by design

The application runs on the operator's own computer and uses authorized API connections.

Audience
Single operator
Market
Türkiye
Output
CSV research export

Purpose

A focused research pipeline

The tool supports research and planning. It does not create advertisements or register domains.

01

Collect candidates

Review operator-provided terms and selected public sources to assemble candidate keywords.

02

Measure demand

Request aggregated keyword metrics for Türkiye from authorized search-planning services.

03

Check domains

Query public RDAP services for selected extensions and export the findings for manual review.

Data handling

Minimal access, transparent use

No public user accounts

The application is not offered as a public SaaS product and does not provide user registration.

Service-account authentication

Google Ads API access is performed by a dedicated service account authorized by the operator.

No advertising activity

The application does not create campaigns, ads, budgets, billing profiles, or payment transactions.

Operator-controlled exports

Research results are exported only when the operator requests a local CSV download.

Important

Research results require independent verification.

Search-volume figures are estimates, not website traffic. An RDAP result is not a reservation or a guarantee that a domain can be registered. The operator must confirm availability with a registrar.
